# ⏰ Moe Kyaw Aung | Time Engineer Portfolio

![Portfolio Banner](https://res.cloudinary.com/dye5qpwii/image/upload/v1778747388/image-1_1_khsx9s.png)

A stunning, interactive portfolio website themed around **time engineering**. This portfolio transforms developer experience into a chronological journey through time capsules, chronograph rings, and warp animations.

## 🚀 Features

### ✨ Core Features
- **Time-Warp Animations** - Smooth, immersive page transitions
- **Chronograph Rings** - Animated countdown and stats displays
- **Timeline Scrubber** - Interactive development journey
- **Time Capsules** - Projects displayed as clickable capsules with ripple effects
- **AI Time Navigator** - Intelligent chatbot (CHRONO) to guide visitors

## 🚀 Quick Start

### Clone Repository
```bash
git clone https://github.com/Dev-moe-kyawaung/time-engineer-portfolio.git
cd time-engineer-portfolio
```
Local Development
# Install any local server (e.g., Live Server in VSCode)
# Or use Python
python -m http.server 8000
Deploy to GitHub Pages
Create a new repository on GitHub
Push all files to the main branch
Go to repository Settings → Pages
Select “Deploy from branch” → main → /root
Click Save
Your portfolio will be live at: https://YOUR_USERNAME.github.io/time-engineer-portfolio/
